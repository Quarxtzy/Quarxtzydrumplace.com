## 📂 Estructura del Proyecto

El sitio web está compuesto por las siguientes páginas interconectadas:

* **`menu.html` (Inicio):** Presentación oficial del blog, introducción al autor y un menú general con los contenidos clave del sitio. Incluye soporte de video (`menu.mp4`) y audio (`menu.mp3`).
* **`pagina1.html` (Técnica de Baquetas):** Guía fundamental sobre agarre de baquetas, iniciación al movimiento de muñeca y una recomendación interactiva sobre la **Técnica Moeller**. Contiene una tabla comparativa detallada de tipos de baquetas (`7A`, `5A`, `5B`), su durabilidad, dinámicas y géneros recomendados.
* **`pagina2.html` (Ejercicios y Canciones):** Sección práctica con una matriz de rudimentos esenciales (Flams, Singles, Doubles, Paradiddles, Buzz rolls, Triples, Paradiddles inversos, Quintuplets, Sextuplets) y una lista de temas recomendados para practicar de artistas como Kiss, Michael Jackson, entre otros.
* **`pagina3.html` (Bateristas Inspiradores):** Un catálogo de referentes musicales divididos por géneros:
* *Rock:* Neil Peart (Rush), Stewart Copeland (The Police), Scott Travis (Judas Priest), Alex González (Maná), Rick Allen (Def Leppard), Joey Jordison (Slipknot), Brad Wilk (RATM/Audioslave), Tim "Herb" Alexander (Primus) y John Bonham (Led Zeppelin).
* *Jazz:* Gene Krupa y Jo "Papa" Jones.


* **`pagina4.html` (Formulario de Postulación):** Sistema de encuestas para postular a clases personalizadas gratuitas.
* **`pagina5.html` (Política de Privacidad):** Documento legal actualizado a julio de 2026 que detalla la protección de datos y el uso de enlaces de afiliados.

## ✨ Características Principales

* **Interfaz Dark Mode:** Diseño moderno con paleta oscura (`#121214`), textos legibles (`#e1e1e6`) y acentos en rojo vibrante (`#ff3e3e`) y naranja (`#f5b041`).
* **Multimedia Nativo:** Uso de etiquetas `<video>` y `<audio>` nativas de HTML5 para tutoriales y soporte auditivo sin dependencias externas.
* **Diseño Limpio:** Tablas estilizadas para comparativas de hardware musical y bloques destacados personalizados para notas importantes de aprendizaje.
* **Navegación Intuitiva:** Sistema completo de botones de retorno (`.btn-back`) y flujos lineales para facilitar la experiencia educativa del usuario.

## 🚀 Instalación y Despliegue Local

Para clonar y visualizar este proyecto en tu entorno local, sigue estos pasos:

1. **Clona el repositorio:**
```bash
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git

```


2. **Navega al directorio del proyecto:**
```bash
cd TU-REPOSITORIO

```


3. **Asegúrate de contar con los recursos multimedia en la raíz:**
* Archivos de video: `menu.mp4`, `tecnica.mp4`, `video.mp4`
* Archivos de audio: `menu.mp3`, `tecnica.mp3`, `audio.mp3`


4. **Abre el archivo inicial:**
Simplemente haz doble clic sobre `menu.html` en tu explorador de archivos o utiliza una extensión como *Live Server* en VS Code para levantarlo localmente.
